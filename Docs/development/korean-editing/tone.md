# 문체

PopPang 글은 해요체로 써요. 독자가 부담 없이 읽고 바로 이해하도록 짧고 분명하게 말해요. 대상별로 어떤 어미를 쓰는지는 [한국어 윤문 원칙의 문체 표](../korean-editing.md#문체)를 봐요. 이 문서는 그 표에 맞춰 문장을 쓰고 바꾸는 방법을 다뤄요.

## 짧고 분명하게 써요

- 한 문장에는 메시지 하나만 담아요.
- 바로 핵심으로 들어가요. `이제 알아보겠습니다`, `앞서 설명했듯이` 같은 말은 빼요.
- 확인한 사실은 돌려 말하지 않아요. 확인하지 못한 내용은 `확인 필요`로 남겨요.
- 독자가 바로 이해할 수 있는 단어를 써요.
- 문장을 꾸미기보다 빨리 이해되게 써요.
- 상투구, 과장, 이모지는 쓰지 않아요. PR 템플릿의 섹션 이모지는 그대로 둬요.

## 한 결과물 안에서 어미를 섞지 않아요

- 한 문서나 한 PR 본문 안에서는 `-요`와 `-다`·`-습니다`를 섞지 않아요. 표와 목록의 명사형 끝맺음은 함께 써도 돼요.
- 문서 일부만 고칠 때는 그 문서의 지금 어미를 따라요. `-다` 문서에 문장을 더하면 그 문장도 `-다`로 써요.
- 문서를 새로 쓰거나 전체를 다시 쓸 때 해요체로 바꿔요. 바꿀 때는 문서 전체를 한 번에 바꿔요.

## 어미를 바꿀 때

`-다`나 `-습니다` 문장을 해요체로 바꿀 때 자주 쓰는 형태예요. 뜻이 달라지지 않게 어미만 바꿔요.

| `-다` | `-습니다` | `-요` |
| --- | --- | --- |
| 한다 | 합니다 | 해요 |
| 했다 | 했습니다 | 했어요 |
| 된다 | 됩니다 | 돼요 |
| 이다 | 입니다 | 이에요, 예요 |
| 아니다 | 아닙니다 | 아니에요 |
| 있다, 없다 | 있습니다, 없습니다 | 있어요, 없어요 |
| 할 수 있다 | 할 수 있습니다 | 할 수 있어요 |
| 하지 않는다 | 하지 않습니다 | 하지 않아요 |
| 해야 한다 | 해야 합니다 | 해야 해요 |

- 받침이 있는 말 뒤에는 `이에요`, 받침이 없는 말 뒤에는 `예요`를 써요. 예: `기본값이에요`, `시트예요`.
- `되요`가 아니라 `돼요`예요.
- 규칙과 설명은 `-해요`로 써요. 독자가 차례대로 따라 하는 절차의 단계는 `-하세요`로 써도 돼요.
- `-므로`, `-하여`처럼 딱딱한 연결 어미는 `-어서`, `-니까`, `-고`로 풀어요.

## 바꾼 예

**수정 전**

> Tuist 버전은 `4.210.0`으로 고정한다. `mise.toml`은 로컬에서, `.tuist-version`은 CI에서 읽으므로 두 값을 함께 고쳐야 한다.

**수정 후**

> Tuist 버전은 `4.210.0`으로 고정해요. `mise.toml`은 로컬에서, `.tuist-version`은 CI에서 읽어서 두 값을 함께 고쳐야 해요.

어미와 연결 어미만 바꿨어요. 버전 값, 파일 이름, "두 값을 함께 고쳐야 한다"는 조건은 그대로 둬요.

PR 본문의 변경 사항도 같은 방식으로 바꿔요.

**수정 전**

```markdown
- 지도 화면의 목록 시트를 SheetKit으로 바꿨습니다.
```

**수정 후**

```markdown
- 지도 화면의 목록 시트를 SheetKit으로 바꿨어요.
```

## 원문 그대로 두는 것

- 직접 인용, 프롬프트 원문, 오류 메시지, 로그는 어미와 맞춤법까지 그대로 둬요.
- 앞뒤 설명만 이 문체로 써요.
- 일부만 고친 요약본을 원문처럼 보여 주지 않아요.

## 확인할 것

- 한 결과물 안에서 어미가 섞이지 않았나요?
- 어미를 바꾸면서 뜻이나 조건이 바뀌지 않았나요?
- 인용, 프롬프트, 오류 메시지를 고치지 않았나요?
