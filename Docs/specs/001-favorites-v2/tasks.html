S01 찜 목록과 하트 토글을 V2로 바꾸고 찜 탭에서 userUuid 빼기

  • 할 일:
    • #131 병합을 확인하고 main에서 이슈와 refactor/#<이슈> 브랜치를 만든다 (H-1).
    • V2FavoriteAPI를 새로 만들고 .list(GET /favorite/popup), .add(popupUuid:)(POST /favorite), .remove(popupUuid:)(DELETE /favorite)를 둔다. 모두 .v2·.access, 등록·해제 본문은 {"popupUuid"} JSON.
    • getFavoriteList(userUuid:)를 getFavoriteList()로 바꾸고 APIResponse<[PopupDTO]>의 data를 읽는다. V1 .getFavoriteList case를 지운다.
    • addFavorite(popupUuid:)·removeFavorite(popupUuid:)를 Repository·Usecase 프로토콜과 구현에 새로 더한다. 기존 userUuid 함수는 그대로 둔다. 세 함수 모두 popupRequest {}로 감싼다.
    • FavoritesFeatureClient 세 함수에서 userUuid 인자를 빼고, FavoritesFeature.State에서 userUuid를 지운다. MainTabFeature는 .init()으로 만든다. Demo를 고친다.

    • toggleLike가 실패하면 토글 실패 문구를 보여 주고 목록을 다시 받는다. 다시 받은 목록도 실패하면 문구만 남기고 이전 목록을 둔다.
    • Data 테스트 FavoriteRepositoryTests를 만든다: 세 요청의 경로·메서드·Bearer·본문(popupUuid만), data 디코딩, 빈 data, 200 빈 본문, 409 4101·404 4102·500 → PopupError.failed, 401 5001 → AuthSessionError.loginRequired.
