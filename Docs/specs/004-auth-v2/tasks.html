S02 공통 틀과 닉네임 화면 새 디자인, 닉네임 추천 API

  • 요구사항: R1, R2, R3, R4
  • 결정: D-3, D-4
  • 할 일:
    • Data: AuthAPI에 .signupNicknameRecommendation(GET /user/nickname/recommendation, 가입 토큰) 추가, 응답 DTO 추가, AuthRepositoryImpl.recommendSignupNickname() 구현. 가입 토큰 만료는 기존과 같이 signupSessionExpired, 그 밖의 실패는 failed.
    • Domain: AuthRepositoryProtocol·AuthUsecaseProtocol·AuthUsecaseImpl에 recommendSignupNickname() -> String 추가. 이 프로토콜을 따르는 가짜 객체도 고친다.
    • AuthFeatureClient에 recommendNickname 추가, AppBootstrap 주입은 live(authUsecase:)가 그대로 처리한다.
    • DSKit UIConstants.swift에 D-4의 새 색 6개를 추가한다.
    • 공통 틀: 상단(뒤로 chevron.left, 진행 막대 270×4, n/3), 제목 ExtraBold 24, 아래 버튼(모서리 10, 52, Medium 15). 닉네임 단계는 뒤로를 숨긴다 (A-1). 건너뛰기는 상단에서 뺀다.
    • 닉네임 화면: 입력칸 + 확인 버튼 + 결과 문구 (A-3), "다른 닉네임 추천받기" 캡슐 버튼 (A-8).
    • Reducer: 진입 시 추천 닉네임을 받아 채우고 .success, 추천받기 → 새 추천, 실패 시 빈 칸 그대로.
    • 새 문구 ko·en·ja를 Localizable.xcstrings에 넣는다.
    • 테스트: 이름에 S02를 넣는다. 진입 시 추천 채움·.success, 추천받기로 바뀜, 추천 실패 시 빈 칸, Data 경로·권한·디코딩.
